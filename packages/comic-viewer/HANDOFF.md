# 토끼 뷰어 작업 인계

이 폴더가 앞으로 사용할 프로젝트 루트입니다. 최종 스크립트는 `toki-viewer-fixed.user.js`, 현재 버전은 `261105000003`입니다.

## 사용자가 원하는 동작

- Android Firefox에서 만화 두 페이지를 가로로 나란히, 화면 전체 크기에 맞춰 읽기. 세로 스크롤 간편 뷰어로 대체하지 말 것.
- 직접 뷰어를 열면 네이티브 전체화면을 요청해 주소창을 숨김. 다음화 자동 복귀에는 브라우저의 사용자 입력 제한이 있으므로 전체화면 버튼 유지.
- 반투명 하단 아이콘 메뉴. 3초 뒤 자동 숨김, 화면 탭으로 표시/숨김. 메뉴가 이미지 높이를 줄이면 안 됨.
- 다음 두 쪽 미리 불러오기. 이전/현재/다음 최대 6개 이미지 객체를 보관하고 넘길 때 재사용.
- 이전화/다음화 버튼과 H/L 단축키. 회차 이동 후 두 쪽 뷰어 자동 복귀.
- 마지막 펼침에서 다음 방향 스와이프, 첫 펼침에서 이전 방향 스와이프 시 메뉴를 표시. 그 외 스와이프는 두 쪽 이동.
- 표지 한 장 설정, 읽기 방향 변경, 실패 이미지 개별 재시도. 첫 장 단독의 켜기·끄기는 같은 사이트의 localStorage에 저장해 재진입·회차 이동·새로고침 후 유지.
- 원본 가로/세로 비율 1.2 이상은 합본으로 판단해 전체 너비에 표시. 직전 일반 페이지는 단독으로 마무리하고 다음부터 두 장씩 묶음.
- 각 이미지 오른쪽 위 아이콘으로 단독 보기/두 쪽 묶기 수동 보정. 선택은 뷰어를 닫을 때 초기화. 아이콘은 메뉴와 함께 숨김.

## 개발과 검증

`npm ci` 후 `npm test`. 현재 64개 테스트가 있습니다. 테스트는 jsdom 기반이고 실제 이미지 다운로드나 실기기 렌더링을 검증하지 않습니다. 사용자는 이전 버전에서 뷰어가 잘 열린다고 확인했습니다.

`261105000003`에서는 첫 장 단독 설정을 `toki-viewer.first-page-alone` 키로 저장합니다. 브라우저 저장소가 차단되면 메모리의 선택을 유지해 재진입·SPA 회차 이동에서 재사용합니다. 켜기와 끄기 모두에 대해 재진입·새 페이지 복원, 다음화 자동 복귀, 저장소 차단 시 동작을 검사했습니다.

`261105000002`에서는 합본 자동 판별과 수동 보정을 추가했습니다. 로드된 원본 또는 뷰어·프리패치 이미지의 자연 크기를 사용하고, 합본 경계를 반영해 표시·이동·프리패치 범위를 함께 계산합니다. 판별·수동 선택은 이미지 URL별로 보관해 URL 교체 시 섞이지 않으며, 이미지 객체가 캐시에서 제거돼도 판별값은 유지합니다. 늦은 판별로 묶음이 바뀌면 현재 시작 이미지가 포함된 펼침을 유지합니다. 합본·일반 이미지 혼합 및 연속 합본, 임계 비율, 지연 로딩 대체 이미지, 늦은 로드와 프리패치, 읽기 방향, 표지 정렬, 수동 보정·터치·메뉴 숨김, URL 교체를 검사했습니다.

`261105000001`에서는 회차 이동 시작 시 이전 이미지 목록을 고정해 DOM이 URL·메타데이터보다 먼저 갱신되는 경우를 처리하고, URL 없는 원본 슬롯의 실패·복구 메시지가 즉시 갱신되도록 수정했습니다. 이동 시작 신호가 없는 임의의 DOM·URL 변경은 여전히 보수적으로 차단합니다.

페이지 예시: https://newtoki1.org/manhwa/33509/1684369 및 https://newtoki1.org/manhwa/10454/103310 . 두 번째 페이지의 인증 데이터를 제외한 33개 슬롯 구조는 `fixtures/newtoki-mobile.html`에 있습니다.
