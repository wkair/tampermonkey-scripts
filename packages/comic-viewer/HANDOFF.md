# 토끼 뷰어 작업 인계

이 패키지는 `tampermonkey-scripts/packages/comic-viewer`에 있습니다. 소스는 `src/main.js`, 메타데이터는 `userscript.json`, 최종 스크립트는 `dist/comic-viewer.user.js`이며, 현재 버전은 `261123000006`입니다.

## 사용자가 원하는 동작

- Android Firefox에서 만화 두 페이지를 가로로 나란히, 화면 전체 크기에 맞춰 읽기. 세로 스크롤 간편 뷰어로 대체하지 말 것.
- 직접 뷰어를 열면 네이티브 전체화면을 요청해 주소창을 숨김. 다음화 자동 복귀에는 브라우저의 사용자 입력 제한이 있으므로 전체화면 버튼 유지.
- 반투명 하단 아이콘 메뉴. 3초 뒤 자동 숨김, 화면 탭으로 표시/숨김. 메뉴가 이미지 높이를 줄이면 안 됨.
- 다음 두 쪽 미리 불러오기. 이전/현재/다음 최대 6개 이미지 객체를 보관하고 넘길 때 재사용.
- 이전화/다음화 버튼과 H/L 단축키. 회차 이동 후 두 쪽 뷰어 자동 복귀.
- 마지막 펼침에서 다음 방향 스와이프, 첫 펼침에서 이전 방향 스와이프 시 메뉴를 표시. 그 외 스와이프는 두 쪽 이동.
- 표지 한 장 설정, 읽기 방향 변경, 실패 이미지 개별 재시도. 첫 장 단독의 켜기·끄기는 같은 사이트의 localStorage에 저장해 재진입·회차 이동·새로고침 후 유지.
- 원본 가로/세로 비율 1.2 이상은 합본으로 판단해 전체 너비에 표시. 직전 일반 페이지는 단독으로 마무리하고 다음부터 두 장씩 묶음.
- 페이지마다 떠 있는 버튼 없이 이미지를 550ms 길게 누르면 보기 설정 팝업 표시. 단독 보기/두 쪽 묶기 수동 보정, 취소·바깥쪽·Escape로 닫기. 마우스 길게 누르기·우클릭과 Shift+F10도 지원. 선택은 뷰어를 닫을 때 초기화.
- 표지 이미지는 우→좌 읽기에서 왼쪽, 좌→우 읽기에서 오른쪽에 배치. 표지 다음의 두 쪽 배치는 기존 방향을 유지.
- 확대·축소 버튼 없이 두 손가락 제스처로 100~400% 연속 확대·축소. 확대 중 한 손가락 드래그로 이동하고 더블탭으로 선택한 맞춤 방식의 기본 크기 복원. 페이지를 넘기거나 배치를 바꾸면 초기화.

- 화면·높이·폭 맞춤을 하단 글자 버튼으로 순환. 수평 여백이 생기면 이미지를 가운데 경계에 붙여 여백은 바깥쪽에만 남김. 높이 맞춤에서 이미지가 칸보다 넓을 때는 바깥쪽 끝을 보존하고 가운데로 넘치는 부분을 숨김. 세로는 중앙 정렬. 합본·수동 단독의 전체 너비 이미지는 중앙 정렬 유지.
- 맞춤 방식과 읽기 방향도 localStorage에 저장하여 다음 화·재진입·새로고침에 유지. 저장소 차단 시 세션 메모리로 유지.

- 메뉴가 나타날 때 화면 우하단에 버전을 함께 표시하고, 메뉴가 숨겨지면 버전도 숨김. 터치를 가로채거나 메뉴와 겹치지 않게 배치.
- 배포 전에 반드시 버전을 올릴 것. `src/main.js`의 VERSION과 `userscript.json`의 version을 함께 올리고 빌드해 설치 파일의 @version도 일치시킬 것.

- 짧은 터치는 왼쪽 40% : 가운데 20% : 오른쪽 40%(2:1:2). 가운데 메뉴, 양옆은 읽기 방향에 따른 이전·다음 이동. 기존 스와이프 유지. 확대 중에는 탭으로 넘기지 않고 드래그로 이동.

## 개발과 검증

저장소 루트에서 `npm ci` 후 `npm test`. 현재 85개 호환성 테스트가 있습니다. `npm run dev:comic-viewer`로 개발 서버를 실행하고 `npm run build:comic-viewer` 또는 `npm run build:all`로 빌드합니다. `npm run test:build --workspace=packages/comic-viewer`는 빌드 후 배포 파일의 메타데이터와 실행을 검증합니다. 의존성 잠금 파일은 저장소 루트의 `package-lock.json`을 사용합니다. 테스트는 jsdom 기반이고 실제 이미지 다운로드나 실기기 렌더링을 검증하지 않습니다. 사용자는 이전 버전에서 뷰어가 잘 열린다고 확인했습니다.

`261123000006`에서는 길게 누르기 팝업과 2:1:2 터치 영역을 추가했습니다. 짧은 탭은 320ms 지연해 더블탭과 구분하고, 길게 누르기는 550ms/10px 기준으로 판별합니다. 이동·핀치·취소·화면 전환 시 대기 동작을 취소합니다. 팝업이 열린 손을 뗄 때 동작이 중복 실행되지 않도록 소비하며, 배경은 inert 처리하고 키보드 초점을 팝업 안에 유지합니다. 원본 URL 변경 시 팝업을 닫아 이전 선택이 새 이미지에 적용되지 않게 했습니다. Chromium 터치 에뮬레이션에서 좌우 탭, 기존 스와이프, 길게 누르기 후 손 떼기, 단독/묶기 전환, 확대 중 탭, 더블탭 복원 및 좁은 화면 팝업을 확인했습니다. Android Firefox 실기기는 미검증입니다.

`261123000005`에서는 수평 여백을 바깥쪽에만 남기도록 수정했습니다. 높이 맞춤은 naturalWidth/naturalHeight와 프레임의 clientWidth/clientHeight를 비교하여 좁으면 안쪽, 넓으면 바깥쪽에 정렬합니다. 이미지 로드·재시도·resize 때 다시 계산합니다. 화면 맞춤의 object-position도 안쪽으로 지정합니다. 전체 너비 단독 이미지는 중앙 정렬입니다.

`261123000004`에서는 메뉴와 함께 나타나는 우하단 버전 표시를 추가했습니다. 버전 표시는 확대되는 이미지 영역 밖에 배치하고 포인터 입력을 통과시킵니다. 하단 메뉴를 조금 올려 좁은 화면에서도 버전과 겹치지 않게 했습니다. 오류 안내는 화면 위쪽에 표시해 버전을 가리지 않게 했습니다.

`261123000003`에서는 높이 맞춤을 바깥쪽 정렬로 변경했습니다. 실제 flex 배치와 프레임 인덱스로 좌우를 판별하므로 읽기 방향·표지 전환·재시도에서도 바깥쪽을 유지합니다. 전체 너비 단독 이미지는 중앙 정렬을 유지합니다. 기존 맞춤·표지·재시도 테스트를 변경된 기대 동작에 맞게 검증했습니다.

`261123000002`에서는 `toki-viewer.image-fit`(contain/height/width), `toki-viewer.reading-direction`(rtl/ltr) 설정 저장을 추가했습니다. 높이 맞춤은 이미지 높이 100%·너비 auto, 폭 맞춤은 너비 100%·높이 auto이며 모두 각 칸의 중앙에 배치합니다. 각 칸의 overflow:hidden을 유지해 넘치는 이미지가 옆 칸을 가리지 않습니다. 맞춤 전환은 확대·이동을 초기화하고, 더블탭은 현재 맞춤 선택을 보존합니다. 호환성 테스트에서 설정 복원·다음화 자동 복귀·저장소 차단·잘못된 저장값·캐시 및 재시도를 확인했습니다. Chromium 로컬 샘플로 실제 크기·중앙 정렬·중앙 경계 잘림·새로고침 후 복원을 검사했습니다.

`261123000001`에서는 표지 배치를 읽기 방향의 반대편으로 수정하고 뷰어 내부 확대·이동을 추가했습니다. 고정 viewport 내부의 펼침 전체에 transform을 적용하며, 두 손가락 중심을 기준으로 확대합니다. 핀치 후 남은 손가락과 확대 중 드래그가 페이지 이동으로 처리되지 않게 분리했습니다. 더블탭은 320ms 이내, 30px 이내의 두 탭으로 판별합니다. 브라우저 자체 확대 대신 뷰어에서 제스처를 처리합니다. 로컬 샘플의 Chromium 터치 에뮬레이션으로 좌우 표지, 핀치 확대, 이동, 더블탭 복원과 세로 화면 메뉴를 확인했습니다. Android Firefox 실기기는 미검증입니다.

`261105000003`에서는 첫 장 단독 설정을 `toki-viewer.first-page-alone` 키로 저장합니다. 브라우저 저장소가 차단되면 메모리의 선택을 유지해 재진입·SPA 회차 이동에서 재사용합니다. 켜기와 끄기 모두에 대해 재진입·새 페이지 복원, 다음화 자동 복귀, 저장소 차단 시 동작을 검사했습니다.

`261105000002`에서는 합본 자동 판별과 수동 보정을 추가했습니다. 로드된 원본 또는 뷰어·프리패치 이미지의 자연 크기를 사용하고, 합본 경계를 반영해 표시·이동·프리패치 범위를 함께 계산합니다. 판별·수동 선택은 이미지 URL별로 보관해 URL 교체 시 섞이지 않으며, 이미지 객체가 캐시에서 제거돼도 판별값은 유지합니다. 늦은 판별로 묶음이 바뀌면 현재 시작 이미지가 포함된 펼침을 유지합니다. 합본·일반 이미지 혼합 및 연속 합본, 임계 비율, 지연 로딩 대체 이미지, 늦은 로드와 프리패치, 읽기 방향, 표지 정렬, 수동 보정·터치·메뉴 숨김, URL 교체를 검사했습니다.

`261105000001`에서는 회차 이동 시작 시 이전 이미지 목록을 고정해 DOM이 URL·메타데이터보다 먼저 갱신되는 경우를 처리하고, URL 없는 원본 슬롯의 실패·복구 메시지가 즉시 갱신되도록 수정했습니다. 이동 시작 신호가 없는 임의의 DOM·URL 변경은 여전히 보수적으로 차단합니다.

페이지 예시: https://newtoki1.org/manhwa/33509/1684369 및 https://newtoki1.org/manhwa/10454/103310 . 두 번째 페이지의 인증 데이터를 제외한 33개 슬롯 구조는 `fixtures/newtoki-mobile.html`에 있습니다.
